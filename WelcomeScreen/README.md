# Short Sleep and Mental Distress in Florida Counties 

## Project Description 
This project examines the relationship between short sleep and frequent mental distress among adults in Florida's 67 counties.

## Research Question
Is there a relationship between short sleep and frequent mental distress in Florida counties?

## Dataset
The project was county-level health data from the CDC PLACES dataset.

## Methods
Python was used to clean and analyze the data. Pearson correlation and linear regression were used to examine the relationship between short sleep and mental distress.

## Results
- Counties analyzed: 67
- Pearson correlation: 0.683
- R-squared: 0.466
- Regression slope: 0.383
The results show a positive relationship between short sleep and frequent mental distress.

## Python Libraries

- scipy

1. Install the required Python libraries.
2. Place the original CSV dataset in the data folder.
3. Run script.py in PyCharm.
